# HOT CPU v0.5.0 — shirt happens

The requested comedy gag now starts at **75%**:

1. She returns to a stable seated pose.
2. A brief cartoon puff changes her into a fully covering blue swim top, with dark shorts unchanged.
3. The shirt follows an eased arc onto the rightmost man's head and completely covers his face.
4. All 24 continuing poses use the matching outfit, and the same man keeps the shirt.
5. Below **65%**, he reaches up and passes the shirt back. A second comic puff restores the original outfit.

The shirt-holder cannot walk off before the handoff finishes. A started return finishes safely if pressure rises again; a short cooldown prevents immediate repeated changes. Before a handoff starts, a canceled trigger can settle without moving the shirt.

The actual shirt-removal frames were unavailable; the costume change is a comic-puff effect, not an undressing sequence. Clothing coverage is maintained throughout.

Validation includes exact 75% activation, 30,000 state-jitter updates, 10,000 scene-pressure changes, all 24 outfit variants, owner retention, continuous attachment boundaries, native transparency and control checks, universal build and signature checks, and a native video capture covering all phases, recovery, and a sudden drop.
