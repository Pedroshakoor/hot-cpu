# Changelog

## 0.2.0 — 2026-11-02

- First public preview of the native macOS companion.
- Live CPU/RAM menu readings and selectable metric source.
- Transparent, draggable desktop window with saved position and five size presets.
- Complete, naturally proportioned tall character sprites.
- Silhouette occlusion without artificial hand-cropping columns.
- Universal Apple Silicon / Intel bundle targeting macOS 14+.
- Offline assets, local preferences, MIT licensing, build CI, and repeatable native checks.
