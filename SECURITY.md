# Security

Pressure Friends reads aggregate CPU counters and virtual-memory statistics locally. It has no account, analytics, network service, keyboard monitoring, or file-scanning feature. Size and position are stored in local macOS preferences.

Do not post credentials or private data in public issues. To report a vulnerability privately, use the repository's GitHub Security advisory feature when available, or contact the maintainer through their GitHub profile before providing sensitive details.

Only the newest release receives fixes. Build from source if you want to inspect the exact code running on your Mac.
