# Contributing

Build on macOS 14+ using Python 3 and Xcode Command Line Tools. Install Node.js 20+ to run tests.

1. Fork and clone the repository.
2. Run `python3 test_preview.py` in a logged-in macOS desktop session.
3. Run `open build/HotCPU.app` and check entry/exit animation, transparency, dragging, menu readings, all sizes, hide/show, and quit.
4. Open a pull request explaining the behavior change and how you checked it. Include a screenshot for visual changes.

Keep changes focused. No external dependencies are needed by the app. Don't commit build outputs, credentials, desktop screenshots, or personal data. Credit the creator and document redistribution rights for any contributed artwork.
